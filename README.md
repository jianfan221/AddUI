**AddUI** is a World of Warcraft UI enhancement pack designed for players who want a polished native interface experience without replacing the entire Blizzard UI. It focuses on **practical improvements**, **visual clarity**, and **modular design** — each feature can be toggled independently.

Rather than bundling a full UI replacement, **AddUI** enhances the existing Blizzard interface with targeted upgrades to unit frames, action bars, minimap, chat frames, cast bars, tooltips, raid frames, cooldown manager, damage meters, and more. Every module is optional and can be turned on or off from the settings panel.

It is built for players who appreciate the **original Blizzard aesthetic** but want it **refined and more functional**.

### 🌟 Features

* **Modular toggle system** – Enable only what you need, disable the rest.
* **Unit frame enhancement** – Improved player, target, focus, and pet frames.
* **Action bar styling** – Clean action bars with optional animation disabling.
* **Square minimap** – Compact minimap with auto-arranging icon management.
* **Chat enhancement** – Styled chat windows with channel switcher and combat timer.
* **Cast bar customization** – Custom textures, width, height, and spell queue adjustment.
* **Raid frame improvements** – Better materials, role icons, absorb shielding display.
* **Cooldown manager** – Built-in cooldown manager with import/export and centering.
* **Damage meter integration** – Auto-reset on M+ start, styling, alignment, and value abbreviation.
* **Tooltip enhancements** – Guild coloring, M+ progress, score details, and more.
* **Convenience tools** – Auto-sell grey items, rapid loot, auto-invite, LFG enhancements, interrupt tracker, and more.

**AddUI** 是一款面向魔兽世界的界面功能增强包，适合希望优化原生界面体验、但不想彻底替换暴雪 UI 的玩家。它的设计重点是 **实用增强**、**视觉清晰** 和 **模块化设计** —— 每项功能均可独立开关。

**AddUI** 不做完整的界面替换，而是在暴雪原生框架上进行针对性增强，覆盖头像、动作条、小地图、聊天框、施法条、鼠标提示、团队框架、冷却管理器、伤害统计等模块。每个功能模块都是可选的，可在设置界面自由开关。

这是一款面向喜欢 **暴雪原生风格**、但希望它 **更精致、更实用** 的玩家的插件。

### 💎 特性

* **模块化开关系统** – 按需启用，不用的功能完全关闭。
* **头像模块增强** – 优化玩家、目标、焦点、宠物头像展示。
* **动作条样式优化** – 简洁动作条，可禁用多余动画。
* **方形小地图** – 紧凑小地图 + 图标自动排列管理。
* **聊天框增强** – 美化聊天窗口，支持频道切换和战斗计时器。
* **施法条自定义** – 自定义材质、宽度高度、施法序列延迟。
* **团队框架增强** – 材质优化、职责图标、吸奶盾/吸收盾显示。
* **冷却管理器** – 内置冷却管理器，支持导入导出和居中对齐。
* **伤害统计整合** – 大秘境自动重置、样式美化、自动对齐、数值简写。
* **鼠标提示增强** – 公会染色、大秘境进度、评分详情等。
* **便捷工具** – 自动卖灰、快速拾取、密语自动邀请、LFG 增强、打断记录等。

## 命令

| 命令 | 功能 |
|------|------|
| `/ad` 或 `/addui` | 打开设置界面 |
| `/aa` | 重载界面 |
| `/ab` | 打开网格线 |
| `/chat` | 配置聊天框 |
| `/sc` | 删除所有宏并恢复默认按键 |
| `/cc` | 打开冷却管理器界面 |
| `/sd` | 配置 ESC → 选项中的各项设置 |

## 快速安装

1. 下载最新版本 [Releases](https://github.com/jianfan221/AddUI/releases)
2. 解压到 `World of Warcraft\_retail_\Interface\AddOns\`
3. 确保文件夹名为 `AddUI`
4. 启动游戏，在角色选择界面确认插件已加载

## 依赖

- 本插件不依赖其他插件，独立运行
- 部分功能（伤害统计样式）可配合 Details! / Skada / TinyDPS 使用
